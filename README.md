# faizullin-site — сайт под ключ в Claude Code

> Напиши Claude «сделай лендинг для моего лид-магнита». Агент сам продумает цель и блоки, напишет тексты, сверстает страницу с плавным моушеном и проверит её на компьютере и телефоне. Сдаст готовый сайт, а не макет.

Это агент (subagent) для Claude Code. Внутрь уже загружен скилл **ui-design**: 84 стиля, 161 палитра, 73 шрифтовые пары, 99 правил UX. Звать его отдельно не нужно.
Подстраивается под твой бренд. Нет бренда — делает чистый минимализм в духе Apple: белый, чёрный и один акцентный цвет.
Лицензия MIT, пользоваться и дорабатывать можно свободно.

## Установка

Две команды в терминале, потом перезапусти Claude Code:

```bash
claude plugin marketplace add yearofcodeking/faizullin-site
```

```bash
claude plugin install faizullin-site@faizullin-site
```

Обновление: `claude plugin marketplace update faizullin-site`. Удаление: `claude plugin uninstall faizullin-site@faizullin-site`.

## Что нужно заранее

| Что | Зачем | Поставить (Windows / macOS / Linux) |
|---|---|---|
| Python 3 | поиск по базе стилей, палитр и шрифтов | `winget install Python.Python.3.12` / `brew install python3` / `sudo apt install python3` |
| Node.js 18+ | сайты на React и Vite, сборка | `winget install OpenJS.NodeJS.LTS` / `brew install node` / [nodejs.org](https://nodejs.org) |
| Chrome или Edge | агент открывает страницу и проверяет её глазами | обычно уже стоит |

Простую страницу (один `index.html`) агент делает и без Node.js.

## Как пользоваться

Открой пустую папку (или папку своего сайта), запусти `claude` и попроси своими словами:

- «используй faizullin-site: сделай страницу для моего бесплатного гайда, кнопка ведёт в Telegram»
- «faizullin-site, переделай мой лендинг, чтобы выглядел дорого и не как шаблон»
- «сделай сайт-визитку для студии маникюра, спокойный и светлый»
- «добавь на сайт блок с тарифами и плавную анимацию появления»

Агента можно позвать и напрямую: `@faizullin-site` в чате или `claude --agent faizullin-site:faizullin-site` при запуске.

## Как он работает

1. **Узнаёт задачу.** Читает твой проект, если он есть. Если нет — задаёт до пяти коротких вопросов: какое одно действие должен сделать посетитель, кто он, что уже есть (логотип, цвета, тексты), какой тон.
2. **Показывает план.** Цель, блоки сверху вниз, цвета и шрифт. Делает после твоего «да».
3. **Собирает.** Тексты живыми словами и без выдуманных цифр. Вёрстка под телефон и компьютер, пружинный моушен на 60 fps, `prefers-reduced-motion` учтён.
4. **Проверяет.** Открывает страницу в браузере на ширине 1440 и 390, смотрит скриншоты, ищет горизонтальную прокрутку, ошибки, мелкие кнопки и слабый контраст. Чинит и только потом говорит «готово».
5. **Ничего не публикует без тебя.** Когда сайт готов, подскажет самый простой бесплатный способ выложить его (Vercel, Netlify, GitHub Pages).

## Как устроено

```
faizullin-site/
├─ .claude-plugin/marketplace.json        каталог (чтобы ставилось одной командой)
└─ plugins/faizullin-site/
   ├─ agents/faizullin-site.md            агент: цель, стиль, тексты, моушен, проверка
   └─ skills/ui-design/                   скилл ui-design: SKILL.md, data/ (стили, палитры, шрифты, UX), scripts/ (поиск)
```

Скилл подгружается в агента полем `skills` в его описании, поэтому весь ui-design у агента в голове с первой секунды.

## Ещё бесплатные инструменты

Все лежат на [github.com/yearofcodeking](https://github.com/yearofcodeking): моушен (`cupmotion`), монтаж (`faizullin-editing`), разбор YouTube-канала (`youtube-analyze`), соцсети (`opencli`), полный набор дизайна (`ui-design`).
